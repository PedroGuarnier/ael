Sincronizar entre celulares

Desligado — os dados ficam só neste aparelho

Para vocês duas verem o mesmo cronograma, o app usa um projeto gratuito do Firebase (Google). Configure uma vez e mande o convite para o outro celular.

O código funciona como senha: quem tem o código vê e edita o cronograma.
Como criar o projeto no Firebase (5 min)
  1. Entre em console.firebase.google.com com uma conta Google e crie um projeto (pode desligar o Analytics).
  2. Em Criação › Realtime Database, crie o banco (modo bloqueado) e, na aba Regras, cole as regras do README do app.
  3. Em Criação › Authentication › Métodos de login, ative Anônimo.
  4. Em Configurações do projeto › Seus apps, adicione um app Web e copie o trecho firebaseConfig para o campo acima.

Prospecção

A busca de leads fica em Clientes › Prospecção. Aqui você só escolhe se o app deve lembrar de rodar a busca toda semana.

Mapa da prospecção

A varredura de bairros usa o OpenStreetMap, que é gratuito e não precisa de chave. Se um dia quiserem a cobertura maior do Google Maps (com avaliações), cole uma chave abaixo e o app passa a usar o Google.

Como criar a chave (10 min)
  1. Entre em console.cloud.google.com. Pode usar o mesmo projeto do Firebase.
  2. Em Faturamento, vincule um cartão (o Google exige, mas a cota gratuita cobre o uso normal).
  3. Em APIs e serviços › Biblioteca, ative Places API (New) e Maps JavaScript API.
  4. Em APIs e serviços › Credenciais › Criar credenciais › Chave de API. Depois edite a chave: restrição de aplicativo Sites com https://pedroguarnier.github.io/*, e restrição de API para as duas APIs acima.
  5. Cole a chave acima.

Radar de conteúdo (IA)

Com uma chave da API da Anthropic (Claude), o app estuda o perfil de cada cliente e pesquisa na internet tendências e virais do nicho, sugerindo posts adaptados. A chave fica só neste aparelho e cada pesquisa custa alguns centavos de dólar.

Crie a chave em console.anthropic.com › API Keys. Se aparecer o erro "must include the anthropic-workspace-id header", copie o ID em console.anthropic.com › Settings › Workspaces (começa com wrkspc_) e cole acima. O radar fica em Clientes › perfil › Radar de conteúdo.

Publicar no Instagram

O Instagram não permite agendar por fora sem conta comercial + API. O app deixa tudo pronto em 3 toques:

  1. Copie a legenda
  2. Envie a(s) foto(s) para o Instagram pelo compartilhar do celular
  3. Cole a legenda e publique. Depois volte e marque como postado.
